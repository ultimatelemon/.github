# ultimatelemon/.github

Organisation-wide defaults for every UltimateLemon repository.

| Path | What it does |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The public profile on [github.com/ultimatelemon](https://github.com/ultimatelemon). |
| [`images/`](images) | Logos used by the profile: `HQ2.png` for dark mode, `HQ2-light.png` for light mode. |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Default issue forms for bugs and feature requests. |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Default pull request description. |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How we work and the short version of our conventions. |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability. |
| [`workflow-templates/`](workflow-templates) | Starter workflows under **Actions** → **New workflow**, built on [`shared-actions`](https://github.com/ultimatelemon/shared-actions). |

GitHub only uses these files for repositories that don't have their own version. A repository's own file always wins.
